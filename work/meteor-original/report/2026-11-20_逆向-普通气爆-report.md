# 普通气爆静态核对报告

2026-11-20。用 Ghidra 12.1.4 只读分析用户提供的 Windows 客户端，并核对同目录的按键配置、动作表和效果定义。原包将 `HITATTACK` 绑定到 F。普通气爆的红色圆柱波、接近 0.8 秒的动作时长，以及未格挡命中后进入倒地，均有本地文件证据。Web 版已按这些行为修正。[本地样本分析范围](../scope.md)

样本为 x86 PE32 `Meteor.exe`，SHA-256 为 `289afb0aa44a47921d167fc24d6d404c60d6d00c299ac27d45fc61e16231b498`。键盘输入涉及 DirectInput 与 USER32。所用 Ghidra 工程与此样本的哈希一致。[原始导入表](../evidence/E-imports.json)

## 证据与调用路径

| 证据 | 发现 | 路径 |
|---|---|---|
| E-BURST-01 · `user.cfg:45` 的 `HITATTACK 70`，`0045d730` 的配置读取分支 | 这份客户端把 `HITATTACK` 配成虚拟键 `0x46`（F）。 | 配置字符串 → 逻辑键 `0x46` 的键位槽 |
| E-BURST-02 · `004d0250`、`004d0350`、`0055d020` 与 `Common/character.act` | 气爆控制器通过动作组 85 选择 367。函数入口允许控制器状态 1、3、4 和 11，后面还有怒气与动作接受检查。 | 虚表 `005aa6a8 + 0x1c8` → `004d0250` → 动作组 `0x55` → Pose 367 |
| E-BURST-03 · `004efb20` 的命令 `0x22`、`0x21`，`004ad530` 的消息 `0x24` | 该控制器路径比较怒气是否至少 60，动作接受后扣除 60。 | 查属性 6 → 动作接受 → `0x21` 发送 `0x24` → 属性 6 减 60 |
| E-BURST-04 · `pmodel/P0.POS` 的 367、103–106 和 `Common/character.amb` 的 30 FPS 文件头 | 气爆帧段为 12293–12316，跨度约 0.77 秒。四个方向的未格挡反应都链接到 112 或 113 的倒地状态。 | Pose 367 命中定义 → 正面 103、背面 106、左侧 105、右侧 104 → 倒地 112/113 |
| E-BURST-05 · `SFX/Pos367.ef` 的 `CYLINDER AttackWave01` 材质键 | 波面从红色开始，早段有白色闪光关键点，随后回到红色，在约 0.5 秒处完全透明。节点键值延伸到约 1 秒。 | Pose 367 的 `EffectID` → `Pos367.ef` → `AttackWave01` |

已核实的调用者包括 NPC 分支 `004fdd70 → 00501010`。物理 F 的绑定和气爆控制器分别得到静态验证，玩家输入到该控制器的完整连接仍待验证。本次对原 EXE 的核对止于静态分析。

## Web 实现与验证

Web 动作约 0.82 秒，普通移动、攻击和跳跃等待收势结束。红色圆柱波约 0.94 秒，渲染补帧时用战斗时钟对齐波面进度。气爆从站立受击解围，震退范围内可见的敌人。未格挡者使用项目已有的倒地和起身流程，格挡者进入格挡反应。伤害为零。动作、红色材质和声音由 Web 版独立制作。

92 项相关回归通过。Chrome 在自由演武默认角色和「栖云古庭」中实测 F 键，怒气从 100 降为 40，并记录到对手先受击、再倒地和起身。全量 876 项中通过 868 项，余下 8 项已分别在修改前的代码上复现。
